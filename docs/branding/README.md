# Radar icon

The selected radar refinement was generated with the built-in image generation
service, using the previous `assets/icon.png` as reference. The approved result
is resized into 16–1024 pixel AppIcon assets and `assets/icon.png`.

Prompt direction: preserve the blue radar, three concentric cyan rings, luminous
scan sector, central hub and connected blue/green device nodes; refine linework,
node rims, depth and enclosure. No text, letters or device mockup. The two earlier
minimal concepts were rejected and are not shipped.
